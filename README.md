## 📌 Sobre este portfólio

Este repositório reúne projetos desenvolvidos na interseção entre
Meteorologia, Ciência de Dados, Estatística e Machine Learning.

Os projetos abrangem análise exploratória de dados, modelagem
estatística, aprendizado de máquina, séries temporais,
geoprocessamento e análise de dados meteorológicos e ambientais.

O objetivo é apresentar não apenas a implementação computacional
das técnicas, mas também sua aplicação a problemas reais,
destacando metodologia, resultados e interpretação dos dados.

## 🎯 Objetivo

Este portfólio tem como objetivo documentar projetos, estudos e
aplicações práticas de métodos estatísticos e computacionais
na análise de dados meteorológicos, climáticos e ambientais.
